# Master Mater

A Minecraft resource pack that renames the “Two by Two” advancement to “Master Mater”.

## Supported Minecraft Versions

Theoretically, it should work with all versions from 1.16.1 through 26.2. Some versions use different resource pack formats and may show an incompatibility warning.

Only tested on 1.16.1 because I only play this version for speedrunning.## Reference

[0 IQ youtuber can't understand my world record - YouTube](https://www.youtube.com/watch?v=91uTrQ8gPUs&t=8669s)

Basically I was watching this video, and I laughed so hard at the “Master Mater” meme. So I decided to make a resource pack that renames the actual advancement JUST FOR FUN :D
